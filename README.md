# Y2Ekinet

Yahoo!乗換案内の検索結果から、新幹線・特急の予約サイトへワンタップでつなぐ Android アプリです。

Yahoo!乗換案内の経路詳細画面で「共有」→ Y2Ekinet を選ぶと、共有テキストから出発駅・到着駅・乗車日・時刻を読み取り、**えきねっとの検索フォームに自動入力した状態で開きます**。あとは内容を確認して「列車を検索する」を押すだけです。

---

## 特徴

- **共有から直接受け取る** — Yahoo!乗換案内の「共有」→「他のアプリに共有」で経路テキストを受信。コピー＆ペーストは不要
- **検索条件の自動入力** — 出発駅・到着駅・乗車日・時刻を抽出し、えきねっとの検索フォームへ入力した状態で開く。検索・予約の実行はユーザー自身が行う
- **経路に応じた予約サービスの提案** — のぞみ・ひかり・こだま・みずほ・さくら・つばめを含む経路では EX予約を優先表示（EX予約はログイン後のサイト構成のため、経路情報のコピーで入力を補助）
- **解析できなくても困らない** — 解析に失敗した場合は受信テキストの表示とコピーにフォールバック
- **アプリ内アップデート** — 設定 → 更新を確認 で GitHub Releases の新バージョンを取得

## インストール

[Releases](https://github.com/makiiii-git/Y2Ekinet/releases) から最新の `app-release.apk` をダウンロードしてインストールしてください。

## 使い方

1. Yahoo!乗換案内で経路を検索し、経路詳細画面を開く
2. 共有 →「他のアプリに共有」→ **Y2Ekinet** を選択
3. 解析結果を確認し「えきねっとで検索（条件を自動入力）」をタップ
4. えきねっとの検索フォームに条件が入った状態で開くので、確認して検索

## プライバシー

- **認証情報・個人情報は収集・保存しません。** えきねっと・EX予約へのログインは、アプリ内ブラウザ上でユーザー自身が各サイトと直接やり取りします
- 通信が発生するのは次の場合だけです: えきねっと／EX予約のページ表示、設定画面での更新確認（GitHub API）
- 共有された経路テキストは端末内でのみ解析し、外部へ送信しません
