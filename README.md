# Y2Eknt

Yahoo!乗換案内の検索結果から、新幹線・特急の予約サイトへワンタップでつなぐ Android アプリです。

Yahoo!乗換案内の経路詳細画面で「共有」→ Y2Eknt を選ぶと、共有テキストから出発駅・到着駅・乗車日・時刻を読み取り、**えきねっとの検索フォームに自動入力した状態で開きます**。あとは内容を確認して「列車を検索する」を押すだけです。

---

## 特徴

- **共有から直接受け取る** — Yahoo!乗換案内の「共有」→「他のアプリに共有」で経路テキストを受信。コピー＆ペーストは不要
- **検索条件の自動入力** — 出発駅・到着駅・乗車日・時刻を抽出し、えきねっとの検索フォームへ入力した状態で開く。検索・予約の実行はユーザー自身が行う
- **JR区間だけを予約対象に** — 地下鉄・私鉄や在来線のアクセス区間を自動で除き、新幹線・特急の乗車駅〜降車駅と発時刻を予約サービスへ渡す
- **EX予約連携（Web版・任意）** — 設定で有効にすると、のぞみ・ひかり・こだま・みずほ・さくら・つばめを含む経路でEX予約（Web版）を開くボタンを表示し、ログイン後の検索フォームへ条件の自動入力を試みる（ログインはユーザー自身が実施。既定は無効。スマートEXはYahoo!乗換案内の公式連携もあります）
- **自動で開くモード** — 設定で「自動で開く」を選ぶと、共有を受け取った直後に予約サービスへ移動。東海道・山陽・九州新幹線の経路はEX予約へ、それ以外はえきねっとへ自動で振り分け
- **解析できなくても困らない** — 解析に失敗した場合は受信テキストの表示とコピーにフォールバック
- **アプリ内アップデート** — 設定 → 更新を確認 で GitHub Releases の新バージョンを取得（GitHub版のみ）
- **検索履歴** — 解析に成功した経路を保存し、あとから同じ条件で開き直せる。カレンダー登録にも対応

## インストール

[Releases](https://github.com/makiiii-git/Y2Eknt/releases) から最新の `Y2Eknt-vX.X.X.apk` をダウンロードしてインストールしてください。

「アプリをインストールできません」と表示される場合は、お使いの端末が32bit（armeabi-v7a）です。
同じリリースにある `Y2Eknt-vX.X.X-arm32.apk` をお使いください。

### GitHub版とGoogle Play版の違い

| | GitHub版（このAPK） | Google Play版 |
|---|---|---|
| 広告 | なし | あり（買い切り課金で非表示） |
| 履歴・自動で開く・EX予約連携 | すべて利用可 | 買い切り課金で解放 |
| アプリの更新 | 設定 → 更新を確認 | Google Play が自動更新 |

GitHub版は Google Play の課金基盤を使えないため、**広告を表示せず、全機能を最初から利用できます**。

## ビルド

```bash
# GitHub Releases 配布用APK（更新チェック・ソースコードリンクあり）
# ABI分割でサイズを削減する。x86_64はエミュレータ専用のため作らない
flutter build apk --release --split-per-abi --target-platform android-arm,android-arm64

# Google Play 配布用AAB
# Play外からのアプリ更新はPlayポリシーで禁止されているため、
# PLAY_STORE フラグで更新チェックとリポジトリリンクを無効化する
flutter build appbundle --release --dart-define=PLAY_STORE=true
```

## 使い方

1. Yahoo!乗換案内で経路を検索し、経路詳細画面を開く
2. 共有 →「他のアプリに共有」→ **Y2Eknt** を選択
3. 解析結果を確認し「えきねっとで検索（条件を自動入力）」をタップ
4. えきねっとの検索フォームに条件が入った状態で開くので、確認して検索

## プライバシー

- **既定では認証情報・個人情報を収集・保存しません。** えきねっと・EX予約へのログインは、アプリ内ブラウザ上でユーザー自身が各サイトと直接やり取りします
- **EX予約のログイン情報の保存は任意です。** 設定で登録した場合のみ、端末内に暗号化（Android Keystore）して保存し、EX予約公式ログインフォームへの自動入力にのみ使用します。外部への送信はなく、設定からいつでも削除できます
- 通信が発生するのは次の場合だけです: えきねっと／EX予約のページ表示、設定画面での更新確認（GitHub API）
- 共有された経路テキストは端末内でのみ解析し、外部へ送信しません
