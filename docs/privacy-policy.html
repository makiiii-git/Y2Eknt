Y2Eknt プライバシーポリシー

本ポリシーは、Androidアプリ「Y2Eknt」（以下「本アプリ」）における利用者情報の取り扱いを定めるものです。

1. 本アプリの機能

本アプリは、Yahoo!乗換案内などから共有された経路テキストを端末内で解析し、「えきねっと」「EX予約」（Web版）の検索フォームへの入力を補助するツールです。

2. 収集する情報と利用目的

2.1 端末内でのみ扱う情報（外部送信なし）

  • 共有された経路テキスト・検索履歴：端末内で解析し、履歴として端末内にのみ保存します。開発者のサーバー等への送信はありません。
  • アプリ設定：動作設定を端末内にのみ保存します。
  • EX予約のログイン情報（任意登録）：利用者が任意で登録した場合のみ、Android Keystoreにより暗号化して端末内に保存し、EX予約のログインフォームへの自動入力にのみ使用します。開発者を含む第三者への送信はありません。アプリの設定画面からいつでも削除でき、アプリのアンインストールでも消去されます。

2.2 第三者サービスに送信される情報

  • 広告（Google AdMob）：本アプリの無料版では、Google AdMob によるバナー広告を表示します。広告配信のため、広告ID・IPアドレス・端末情報等が Google により収集されることがあります。詳細は Googleのプライバシーポリシーおよび AdMobのデータ利用についてをご確認ください。 プレミアム（アプリ内課金）を購入すると広告は表示されなくなります。
  • アプリ内課金（Google Play）：決済は Google Play が処理します。開発者がクレジットカード番号等の決済情報にアクセスすることはありません。
  • えきねっと・EX予約のWebサイト：本アプリ内のブラウザ（WebView）で各サイトを表示する際、利用者の操作および入力補助として、検索条件やログイン情報が各サイトへ直接送信されます。これは利用者が各サイトを通常のブラウザで利用する場合と同等の通信です。各サイトでの情報の取り扱いは、各運営者（JR東日本・JR東海等）のプライバシーポリシーに従います。
  • 更新の確認（GitHub）：アプリの更新確認のため GitHub API へアクセスします。この際、IPアドレス等の接続情報が GitHub により処理されます。

3. 開発者による情報収集

開発者は、独自のサーバー等で利用者の個人情報を収集・保存することはありません。アクセス解析も行っていません。

4. 情報の第三者提供

開発者が利用者の情報を第三者に販売・提供することはありません（上記2.2の各サービスによる処理を除く）。

5. お子様のプライバシー

本アプリは特定の年齢層を対象としたものではなく、開発者が児童の個人情報を意図的に収集することはありません。

6. ポリシーの変更

本ポリシーを変更する場合は、本ページで告知します。重要な変更がある場合は、アプリの更新情報等でもお知らせします。

7. お問い合わせ

本ポリシーに関するお問い合わせは、GitHubリポジトリのIssueからお願いします。
